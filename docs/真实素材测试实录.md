# 真实素材测试实录

用古腾堡计划（gutenberg.org）的公版书全文实测导入解析，发现并修复两个模拟测试测不出的真实格式问题：

## 1. 圆圈零章节号

《三國志演義》第 100-110、120 回的回目写作"第一○○回""第一二○回"，用符号 ○（U+25CB）当零。原章节正则的数字字符表不含 ○，导致 12 个回目没被识别，整章正文被并进上一章。

**修复**：章节数字字符表加入 〇（U+3007）和 ○。

## 2. 正文注解行误判成标题

《紅樓夢》正文里有"第四回中既將薛家母子在榮府內寄居等事略已表明，此回則…"这类以"第X回"开头的批注行，被误判成章节标题，把一章劈成两半。

**修复**："第X回"后面必须跟分隔符（空白、冒号、顿号等）或行尾，才算标题。

## 结论

模拟文件能精确覆盖结构边界（编码、BOM、空文件、换行），真实素材才能暴露"世界有多乱"（异体字符、版本瑕疵）。两类测试都要有：

- 结构边界 → 生成模拟文件逐项断言
- 真实格式 → 抓取公版书全文跑一遍

《紅樓夢》该版本"第四十五回"回目在文件里本身就重复了一次，属版本扫描瑕疵，解析器忠实还原，不计为 bug。
